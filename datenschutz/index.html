Besuch der Website

Die Website wird bei GitHub Pages betrieben (GitHub Inc., USA). Beim Aufruf einer Seite verarbeitet der Anbieter technisch notwendige Daten wie IP-Adresse, Datum und Uhrzeit, aufgerufene Seite und Browserangaben, um die Website auszuliefern und die Sicherheit zu gewährleisten.

Diese Website setzt keine Cookies und verwendet keine Analyse- oder Werbedienste. Die Schriften sind direkt auf dieser Website gespeichert; es werden keine Schriften von fremden Servern geladen. Damit die Einstiegsanimation nicht bei jedem Seitenwechsel erneut läuft, merkt sich Ihr Browser für die Dauer der Sitzung, dass sie bereits gezeigt wurde. Dabei werden keine Personendaten gespeichert; der Eintrag wird beim Schliessen des Browsers gelöscht.
